What changes between PN boutons, KC claws and KC somata — and what we think does it

Figure 7 analysis, updated 2026-10-22 with the labmate’s APL-silencing matrices. Each column sits under the synapse or step it describes; rows give the observed change, the mechanisms ranked by how the data treat them, and the dataset, analysis and file behind each claim. Terms: claws beyond E[claws | boutons] is each odor pair’s claw similarity minus what a fit from its bouton similarity predicts (z units); it splits into an odor part (one value per odor) and a pair part (the rest). Somata beyond E[somata | claws] is built the same way. The claws→somata change is the plain difference z(somata) − z(claws) per pair, with no fit. The APL effect is z(silenced) − z(intact) per pair.
